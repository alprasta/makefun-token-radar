Which pre-token protocol is worth farming next?

Every protocol below records no token, ranked by what its launch would be worth if its record stayed as it is. The watchlist is the floor, never the ceiling: the board also carries the early pre-token protocols below the $50M floor.

How the value is computed — model radar-2

implied value = TVL × category multiple × growth × maturity × chains

  • Category multiple. The median market-cap / TVL of the live-token protocols in the same category in this same snapshot — the market's own price for that kind of protocol. A category needs at least 5 live comparables to price its own rows; otherwise the row is priced at the overall live-token median. The multiple is clamped to 0.05–0.60.
  • Growth. 1 + (7-day TVL change, clamped to −60%…+120%) / 100 × 0.5. No 7-day figure counts as 0%.
  • Maturity. 0.6 + min(age in days, 1095) / 1095 × 0.4. Age is the time from first listing to the snapshot date; an unknown listing date counts as 365 days. A protocol that has run longer with no token scores higher.
  • Chains. 1 + 0.10 × (1 − 1 / chains). One chain scores 1.00; many chains approach 1.10.

One function scores every row from the snapshot's own figures — no protocol name is special-cased and no row is hand-picked. “Records no token” means DefiLlama's record carries no market cap, no CoinGecko id and no symbol; it is the record, not proof a token does not exist. Protocols whose token already trades are set aside in the Live view with their market caps, never mixed into the ranked board. Implied value is this entry's own estimate, not a price and not a prediction that a token will launch.
