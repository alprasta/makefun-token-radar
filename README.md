Token Radar ranks 198 pre-token protocols by an implied launch value — TVL priced at the live market's own median market-cap/TVL for the protocol's category, adjusted for 7-day growth, age with no token, and chain count — with a six-step farm plan for each, on a filterable dark dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
